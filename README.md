# States and Capitals

Two free learning games for the 50 U.S. states and their capitals.

- **Map Game** (`index.html`): find states on a U.S. map, name capitals, place states by dragging, and explore facts about each state. Scores are saved in the browser on each device.
- **Flashcards** (`flashcards.html`): flip cards and a multiple choice quiz.

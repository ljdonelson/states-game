# States and Capitals

Two free learning games for the 50 U.S. states and their capitals.

- **Map Game** (`index.html`): each state flashes on a U.S. map, and a star marks the capital's real location. Includes Find the Capital, Name the State, Flip Cards, and Explore (with populations, mottos, and trivia). Scores are saved in the browser on each device.
- **Flashcards** (`flashcards.html`): flip cards and a multiple choice quiz.

Populations are from the 2020 U.S. Census. Map outlines come from the us-atlas project (U.S. Census Bureau cartographic boundaries).
